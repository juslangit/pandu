Minimal Pandu example

This page uses Pandu's default theme with two overridden colours and nothing else. View the source: it is the complete setup. The "Products" panel is a mega-menu, "Company" is a dropdown, and below 960 px the links move into a drawer.

Note that "Products" and "Company" link to their section pages when JavaScript is off; with it on, the script adds an overview link at the top of "Products" because the panel did not include one.
